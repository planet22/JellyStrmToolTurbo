    Strm Tool Turbo Settings

    Auto extraction

    Automatically extract media info for new strm files
    When enabled, new strm files will automatically extract media info in the background without manual task execution
    Refresh delay (ms)
    Milliseconds to wait after each media info refresh to avoid overwhelming remote servers
     1000ms

    Media info cache

    Enable media info caching
    When enabled, extracted media info will be saved to xxx.strmtool.json files to avoid repeated probing
    Metadata restore timeout (minutes)
    Maximum time to wait for metadata restoration when strm file size is reset (1-30 minutes)
     5m
    Import existing cache when data missing from Jellyfin
    When enabled, if a cache file exists for a strm file but Jellyfin has no media info for it, the cached size, runtime and container are imported into Jellyfin's database to match the cache

    Extraction throughput

    Maximum concurrent extractions (restart required)
    Maximum number of concurrent media info extraction tasks
     5

    Force Refresh Options

    Ignore existing media streams
    When enabled, will always execute refresh regardless of whether media stream info already exists (cache can still be used)
    Ignore cache
    When enabled, will always fetch from remote server directly, ignoring cache files (will still check if media streams exist)
